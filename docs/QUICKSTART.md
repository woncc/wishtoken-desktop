# 使用说明

## 安装

只从本仓库 Releases 下载客户端，并按发布页 `SHA256SUMS.txt` 校验。Windows 提供安装程序与便携 ZIP；macOS 提供 Apple Silicon / Intel ZIP。安装客户端无需自行安装 Go 或 Node.js。

macOS 13+：解压并将 WishToken Desktop.app 拖入“应用程序”。当前测试包没有 Developer ID 签名或 Apple 公证。系统阻止打开时，先确认下载来源和校验值，再通过系统“隐私与安全性”中的“仍要打开”批准这个应用。不要关闭系统整体安全检查。若系统不提供该操作，请保留错误信息，等待签名版本或自行从源码构建。

官方 Codex App / CLI 需另行安装。在“选择 Codex App 路径”中可指定安装位置。Windows 商店版使用应用包启动上下文；Mac 使用应用包内部程序。

## 导入与切换

支持单个或多个 JSON 文件，也可粘贴 JSON。客户端不会向渲染页面返回 Access Token 或 Refresh Token。账号卡片显示上游报告的用量窗口和重置时间；没有额度结果时显示待查询，不虚构剩余值。

导入后选择账号、BPS / 原生通道、模型和推理档位。App 无需项目目录；CLI 需要目录。账号及通道绑定到独立工作空间，已经打开的实例仍使用原账号。要切换已运行 App 的设置，请退出该独立实例再重新启动。不会修改全局 `~/.codex` 或原 Cockpit 实例。

BPS 403 与原生权限、账号额度是不同状态；可以手动选原生，但不会自动回退。原生可用也不能证明 BPS 权限恢复。

## App 额度与快速模式

隔离 App 配置携带实际账号的本地 Access Token 快照，通过回环身份适配器读取官方账号和额度；模型请求仍走本地桥及所选通道。独立 App 不持有账号的 Refresh Token。主客户端负责凭据续期；快照失效后重新启动该账号的隔离 App 以重新生成。

原生支持标准／快速偏好；BPS 当前只支持标准。快速向上游请求 `priority`，可能消耗更多额度。上游可能报告 `default`；“运行记录”会分别显示请求等级和返回等级。未报告的字段显示“未报告”，不会替代成请求值。

## 鹈鹕作品对比

选择同一提示词、模型、推理强度与通道后再比较账号。一次最多 20 个账号，可设置 1–5 个并发。测试会消耗额度，最长 15 分钟；支持取消、重试、历史预览及 HTML 导出。模型生成 HTML 在禁外网、无主窗口权限的沙箱中展示。手动导出的 HTML 脱离客户端后，请自行检查再运行。

## 升级、数据与退出

默认数据目录为 `~/.gptbridge-desktop`，本地端口为 8792。继续沿用早期 GPTBridge 的数据位置及应用标识，重命名为 WishToken Desktop 不会复制或自动删除原有凭据。请勿同时运行两个版本占用同一数据目录。

更新前退出旧版客户端；关闭窗口只隐藏到托盘，托盘“退出客户端”才停止本地桥。升级前可在自己的加密存储中备份本地目录，勿上传仓库或工单。卸载默认保留账号数据；需要清除时先停止所有独立实例，再手动删除自己的数据目录。

## 排查

- `token_revoked` / 401：凭据已被上游拒绝；重新获取有效授权 JSON。不是通过降并发即可解决。
- BPS usage-policy 403：通道权限被拒；手动测试原生或使用另一有权限的授权账号。
- 429：查看官方额度和冷却提示；真实额度耗尽需要等待重置。每个账号最多 5 个在途请求。
- App 额度不显示：更新官方 App，并重新启动隔离实例刷新身份快照；提交问题时不要附 `auth.json`。
- 模型报错：保留通道、请求模型、返回标识和错误代码，不自动替换模型或推理档位。
