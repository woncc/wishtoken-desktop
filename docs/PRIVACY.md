# 隐私与数据流

## 保存在本机的内容

导入的账号凭据、配置、额度快照、独立 Codex 会话、项目目录、鹈鹕提示词和生成作品保存在本地用户目录。账号存储目前是受文件权限保护的 JSON，不是加密保险库；本项目没有声称使用系统钥匙串加密全部凭据。请保护操作系统账户、磁盘和备份。

主 Codex App 和独立实例使用实际 Access Token 的私有快照读取账号额度，新写入身份不包含 Refresh Token。主应用接管的原配置备份可能含此前登录凭据，保存在客户端私有数据目录，不上传、不打包。主服务的自动续期会使用导入的 Refresh Token，可能轮换它；不要让多个服务同时刷新同一份授权。

## 网络请求

- 上游模型、额度与授权接口收到完成对应操作所需的凭据和请求内容；具体通道由用户选择。
- 用户配置代理时，请求经过该代理。
- 官网、GitHub、版本和邀请码按钮仅在点击时通过默认浏览器打开固定 HTTPS 地址。官网地址包含静态来源参数，没有账号标识或令牌。
- 客户端没有遥测、广告 SDK，也不自动把账号发往 WishToken。没有后台自动下载或安装更新。

## 分享诊断信息

公开反馈请仅提供版本、操作系统、通道、请求/返回模型、错误代码和去除身份信息的复现步骤。不要上传原始账号文件、完整本地数据目录、真实会话、截图中的邮箱、项目路径或完整日志。没有一键“全部日志上传”功能。

仓库和发布文件通过排除规则、源文件扫描及制品白名单检查，禁止包含账号导出、交接记录或本地调试捕获。扫描是预防措施，不代替人工审查。
